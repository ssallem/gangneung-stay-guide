# 가을, 강릉에서

2026년 10월 31일~11월 1일, 40대 후반 남성 5명을 위한 상상초당·산타비치·더강문풀빌라 비교 HTML.

공개 페이지: https://ssallem.github.io/gangneung-stay-guide/

사진, 가격 예시, 후기 요약, 위치, 5인 추가비와 식비 계산기를 포함합니다. 실제 숙박일의 요금/잔여 객실은 미확인입니다. 사진·자료 출처와 확인일은 페이지 하단 및 photo-sources.json에 기록했습니다. 사진 저작권은 원 권리자에게 있으며 코드 라이선스와 별개입니다.

정적 HTML/CSS/JavaScript로 빌드 없이 동작합니다. GitHub Pages는 main 브랜치 루트에서 게시합니다.
